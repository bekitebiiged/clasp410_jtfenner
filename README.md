# clasp410_jtfenner
This is my repository for coursework for CLIMATE410 at University of Michigan (Fall 2026). 

Currently the plan is to have the following structure for this repository: 
  * Labs
    - Each folder represents a Lab assignment
    - Title of folder represents assignment
    - Each folder should have a .py script and lab report
    - May have Figures subfolder
  * Homeworks
    - Each folder within Homeworks represents a homework assignment
    - Title of folder represents assignment
    - Should have a .py file
  * In-Class Activities
    - This represents a collection of scripts written during class and class notes
